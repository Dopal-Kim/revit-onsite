## 문제

### 높음
**H1. 대화상자 [?] 도움말 버튼이 오류를 냄**
- 화면: 프로젝트 설정 창 [?] → 메시지 "도움말을 열지 못했습니다. An error occurred trying to start process …:/Users/admin/Desktop/%EC%8B%9C%EC%8A%A4… with working directory 'C:\Users\admin\Desktop\시스템2\build-up-2\revit'. 지정된 파일을 찾을 수 없습니다."
- 원인 추정: 한글 경로를 %인코딩한 `file:` URI 문자열을 그대로 `Process.Start` 에 파일 이름으로 넘김(UseShellExecute 없이 또는 URI→경로 변환 없이). 리본 F1(ContextualHelp)은 Revit이 열어서 동작함.
- 기대: ui_spec §7 [?] = 도움말 해당 앵커. 시공자가 누르면 영문 예외 문구가 그대로 보임.
- 고칠 점: `Process.Start(new ProcessStartInfo(uri.AbsoluteUri) { UseShellExecute = true })` 처럼 셸로 열기(또는 Edge 실행 파일 + URI 인수). 오류 문구는 한국어 한 줄로.
- 캡처: `ui2_11_설정창_도움말버튼_오류.png`

### 중간
**M1. 문서가 열려 있어도 회색인 버튼** — 대시보드(명세 "항상"), 색 범례(명세 "뷰"), 뷰·필터 준비(명세 "매개변수 연결됨" — 연결된 뒤에도 회색). 미구현이면 괜찮지만, 대시보드는 판정 결과를 보는 주 화면이라 시연 흐름이 판정 후 막힘. (`ui2_04`)

**M2. 사용 조건 순서가 명세와 어긋남** — 데모 사본에서 해체 판정이 구역 생성 **전부터** 활성(`ui2_03`). KBIM 사본에선 설정 저장 전이라 구역·동바리 생성은 회색인데 설치 검측은 활성(KBIM 파일에 이미 구역이 있어서로 보임 — "구역 13개 검사"). 명세 흐름: 설정 → 생성 → 설치 검측 → 판정. 판정은 "타설 기록 있음"이 조건이므로, 구역이 없을 때 회색이어야 시공자가 순서를 헷갈리지 않음.

**M3. 판정 색이 기본 3D에서 잘 안 보임** — 기본 3D(와이어프레임·투명)에서 10–12F 파랑이 옅은 하늘색, 9F 주황(존치 연장)이 구분 안 됨(`ui2_22`, `ui2_23`). 판정 메시지는 "상태 색 필터를 '{3D}' 뷰에 적용". 제안: 판정 때 "On-Site 검측" 3D 뷰(음영, 벽·창 반투명 또는 숨김, 구역 솔리드 채우기)를 만들어 그 뷰에 적용 — 명세 §2 "뷰·필터 준비"와 연결.
