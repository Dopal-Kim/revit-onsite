# Revit On-Site — 화면 명세 (UI spec)

목표: Revit 기본 탭(구조·수정·뷰)과 나란히 놓아도 **Revit의 일부처럼 보이는 것**. 새 화면 요소를 발명하지 않고 Revit이 이미 쓰는 컨트롤만 쓴다.
API 근거: Revit 2026 API 문서 "Ribbon Panels and Controls", `RadioButtonGroup`, `UIApplication`(SelectionChanged·ThemeChanged·RegisterContextMenu·RegisterDockablePane), `UIThemeManager` — Autodesk Product Help 로 확인함.
담당: 이 명세·아이콘 = 총괄 세션, 구현 = Revit 작업 세션(`revit/RevitOnSite/`).

---

## 1. Revit 화면 규칙 (따라 할 것)

| 항목 | Revit 기본 동작 | Revit On-Site 적용 |
|---|---|---|
| 큰 버튼 | 32×32 아이콘 + 아래 글자 2줄 이내 | 패널마다 주 기능 1–2개만 큰 버튼 |
| 작은 버튼 | 16×16, 2–3개 세로 쌓기 (`AddStackedItems`) | 보조 기능. 라디오 그룹·분할 버튼은 쌓을 수 없음(API 제약) |
| 토글 | 라디오 그룹(`RadioButtonGroup` + `ToggleButtonData`): 하나만 눌린 상태 | "표시" 토글: 상태 / 강도 / 일정 |
| 드롭다운 | 분할 버튼(`SplitButton`, 마지막 사용 항목이 위로) | "데이터 가져오기": 공정표·센서·공시체·기상 |
| 슬라이드아웃 | 패널 이름 옆 ▾ 를 누르면 펼쳐짐 (`AddSlideOut`, 마지막에 추가) | 고급 설정(색상 기준, 판정 기준값 보기) |
| 툴팁 | 짧은 설명 → 오래 올리면 긴 설명 + 그림 + "F1 키를 누르면 도움말" | 모든 버튼에 `ToolTip`·`LongDescription`·`ToolTipImage`·`SetContextualHelp` |
| 사용 가능 여부 | 쓸 수 없는 버튼은 회색 | `IExternalCommandAvailability` (예: 구역이 없으면 판정 버튼 회색) |
| 선택 시 탭 | 요소를 고르면 "수정 \| ○○" 상황별 탭 | 구역·동바리 선택 → "수정 \| 동바리 구역" 탭 (§4) |
| 우클릭 메뉴 | 요소 우클릭 메뉴 | `RegisterContextMenu` 로 "판정 근거 보기" 등 추가 |
| 도킹 창 | 특성·프로젝트 탐색기처럼 붙였다 뗐다 | 대시보드 = `RegisterDockablePane` (§5) |
| 진행 안내 | 상태 표시줄 문구 ("요소를 선택하십시오") | `PickObject(..., statusPrompt)` 에 한국어 안내, Esc 로 취소 |
| 메시지 | `TaskDialog` (제목·본문·확인/취소, 자세히 보기) | 경고·확인은 전부 `TaskDialog`. 직접 만든 메시지 창 금지 |
| 되돌리기 | 명령 하나 = 실행 취소 한 번 | 버튼 하나 = 트랜잭션 그룹 하나, 이름 = 버튼 이름 (실행 취소 목록에 "Revit On-Site: 구역·동바리 생성") |
| 테마 | 라이트/다크 (`UIThemeManager.CurrentTheme`, `ThemeChanged`) | 아이콘 2벌, 테마 바뀌면 즉시 교체 |
| 단축키 | 키보드 단축키 대화상자에 명령이 자동 등록 | 권장 단축키 §2 마지막 열 (사용자가 등록) |

## 3. 버튼 글자·문구 규칙
- 버튼 글자 ≤ 6자(한 줄) 또는 4+4자(두 줄). 동사보다 명사("판정", "타설 등록").
- 툴팁 첫 문장은 "…합니다." 로 끝나는 한 문장. 긴 설명에 규정 근거와 "모델을 바꾸는지" 명시.
- 결론 문구는 정의서 규칙 그대로: **"해체 승인 요청 가능" / "존치"**. "해체하세요", "승인됨" 같은 지시·승인 문구 금지. 서명란은 비움.
- 오류 문구 = 무엇이 문제 + 어떻게 고치나. 예: "구조 바닥이 있는 레벨을 찾지 못했습니다. [모델 진단]으로 인식 결과를 확인하세요."

## 4. 선택 시 상황별 탭 "수정 | 동바리 구역" / "수정 | 동바리"
Revit 의 "수정 | 바닥" 탭처럼, 구역(SHR_GenBy 태그 DirectShape)이나 동바리를 선택했을 때만 나타난다.
- 구현: `UIApplication.SelectionChanged`(2026 API 확인) 로 선택을 감지 → 탭 표시/숨김. 공개 API 에 상황별 탭 생성 기능은 없으므로 `AdWindows.dll`(Autodesk.Windows.ComponentManager.Ribbon)의 `RibbonTab.IsContextualTab` 를 쓴다 **[비공식 API — 동작 확인 필요]**. 실패하면 같은 명령을 우클릭 메뉴(`RegisterContextMenu`)로 제공한다.
- 탭 색: Revit 상황별 탭과 같은 강조색(Revit 이 자동 적용하는 contextual 스타일을 따름, 임의 색 지정 금지).

| 탭 | 패널 | 버튼 |
|---|---|---|
| 수정 \| 동바리 구역 | 구역 | 판정 근거 · 타설 등록(선택 구역) · 공시체 입력 · 승인 기록 |
| | 편집 | 구역 나누기 · 구역 합치기 · 동바리 다시 배치 |
| 수정 \| 동바리 | 동바리 | 높이 맞추기 · 검측 결과 기록 · 이음 수 입력 |

F1 도움말: `docs/help/index.html#<명령 클래스>` (§2 명령). 상황별 탭은 앵커 `ctx-zone`·`ctx-shore`, 버튼 `ctx-reason` `ctx-pour` `ctx-cylinder` `ctx-approve` `ctx-split_zone` `ctx-merge_zone` `ctx-replace_shores` `ctx-fit_height` `ctx-inspect_record` `ctx-splice_count` — 명령 클래스 이름은 `CmdCtx` + 앵커 뒷부분 PascalCase (예 `CmdCtxSplitZone`).

## 5. 대시보드 (도킹 창)
- `RegisterDockablePane`, 기본 위치 = 오른쪽(특성 창 옆 탭), 제목 "Revit On-Site".
- 모양은 Revit 특성 창과 같은 계열: 라이트 = 흰 배경, 다크 = #3B4453 배경·머리글 #222933 (실측), Segoe UI 9pt, 그룹 머리글 띠, 표는 줄무늬 없음 + 선택 행 #2B7BB3.
- WPF 스타일은 `design/wpf/OnSiteTheme.Light.xaml`·`OnSiteTheme.Dark.xaml` (도킹 창), `OnSiteDialog.xaml` (대화상자, 항상 라이트) 를 병합해서 쓴다.
- 구성 (위→아래):
  1. **기준일** 줄: 날짜 선택(DatePicker) + [오늘] + [판정] 버튼
  2. **요약 칩** 3개: 해체 승인 요청 가능 n구역 · 존치 n구역 · 공시체 시험 필요 n구역
  3. **층 × 구역 격자**: 행 = 층(위층이 위), 열 = 구역, 칸 색 = §6 상태색, 칸 글자 = 예측 해체일(MM-DD). 칸 클릭 → 모델에서 그 구역 선택·확대, 두 번 클릭 → 판정 근거
  4. **타임라인 막대**: 날짜 슬라이더 + ▶ 재생 / ❚❚ / 속도(1일·1주/초) — 움직이면 활성 3D 뷰 색이 그 날짜 상태로 바뀜
  5. **경고 목록**: schedule.py·evaluate.py 경고 그대로 (예: "2026-10-23 에 동바리 5개층분 동시 필요")

## 7. 대화상자 규칙 (WPF)
- WinForms 금지 → WPF `Window`, `Owner` = Revit 주 창(`MainWindowHandle`), `WindowStartupLocation=CenterOwner`, 크기 조절 불가(작은 창)/가능(표가 있는 창).
- 글꼴 Segoe UI 9pt(한글은 맑은 고딕 자동 대체), 여백 12 px, 입력 칸 높이 23 px, 레이블은 왼쪽 정렬 고정 폭.
- 아래 버튼: 오른쪽 정렬 **[확인] [취소]** (+ 필요하면 [적용]), 왼쪽 끝 **[?]** 도움말. Enter = 확인, Esc = 취소.
- 날짜는 `DatePicker`, 숫자는 단위가 붙은 칸("7 일", "3 개층", "5 °C"), 파일은 [찾아보기…].
- 기본값은 미리 채움. 값이 잘못되면 칸 아래 빨간 한 줄 안내, [확인] 비활성.
- **테마 (실측 2026-11-04, Revit 2026.3 다크 화면 캡처 `revit/screens/02_addins_tab.png`·`03_open_dialog.png`):** Revit 은 다크 테마에서도 **모달 대화상자(열기 등)는 라이트 그대로**(배경 #F3F3F3/#FFFFFF) → 우리 대화상자도 항상 라이트. 테마를 따라가는 것은 리본·도킹 창·특성 창 계열뿐.
  - 다크 프레임 색: 제목줄·뷰 배경 #222933, 리본·패널·특성 창 배경 #3B4453, 선택 강조 #2B7BB3, 글자 #F5F5F5.
