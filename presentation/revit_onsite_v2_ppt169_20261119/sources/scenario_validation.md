## 시나리오별 설명

### S0 정의서 §4.2 계절별 fck 도달 일수 재현 — PASS

11월·1월 타설은 보온(5 °C)만으로 fck 도달이 24–29일 → 7일 사이클 3개층(21일)로는 모자람. 가열 양생(15 °C)이면 18일.

### S1 데모 기준 — 샘플 판정 — PASS

9층 공시체 평균은 6구역 모두 기준 이상(24.8 MPa 이상)이지만, 센서 IDW 구역 최소 강도가 북측 그늘(최소 위치 (0.25, 9.25)) A2·B2 에서 24 MPa 미만 → 공시체 한 장으로 층 전체를 해체하면 놓치는 구역을 위치 근거로 잡아냄.

### S2 화정형 — 1개층만 존치 — PASS

지지층이 1개면 타설 하중 1.2(5.44 + 0.5) + 1.6·2.5 = 11.13 kN/m² 를 여유 5.17 kN/m²·√(f/fck) 한 장이 받아야 해서 하중비가 2배를 넘는다. 1층은 기초가 받쳐 하중비 0 이지만 층수 규칙만으로도 위반.

### S3 겨울 첫 타설 — 가이드라인 최소 3개층으로 부족 — PASS

겨울(12/1)은 위반 층이 1–12층으로 10/1 시작(5–12층)보다 넓다 → '가이드라인 최소 3개층만 지키면 겨울에 위반'(정의서 §1)을 엔진이 재현. (v6: 공정 계획의 동시 세트 수 비교는 공정 계산과 함께 뺌)

### S4 공시체 미달 — PASS

센서 추정(구역 최소 24.1 MPa)이 기준을 넘어도 공시체가 미달이면 승인 요청을 막는다.

### S6 공시체 없음 — PASS

센서만으로는 승인 요청이 나가지 않는다 (국내 기준상 강도 확인 근거는 현장양생 공시체). Revit 색은 노랑(상태 4).

### S7 최상층 토핑아웃 — 층수 게이트 — PASS

최상부 층은 위로 3개층이 영원히 생기지 않으므로 게이트를 통과시키되, 강도 근거(공시체)는 그대로 요구한다. 이 해석은 규정 문구가 아니라 팀 해석 [가정] — 발표에서 그렇게 밝힐 것.

### S8 KBIM 실측 동바리 높이 — 설치 검측 — PASS

데모 모델(층고 3.0 m)에서는 아무 플래그도 안 나오지만, 실제 IFC(업무시설 층고 4.1 m, 1층 아래 6.1 m)에서는 기준층부터 수평연결재, 1층 하부는 3가지가 모두 걸린다. 예: 높이 5900 mm > 3500 mm → 2방향 2000 mm 이내마다 (최소 2단) — 수평연결재 설치 기록 없음, 현장 확인.

### S9 1본당 하중 — PASS

1.2 m 간격은 여유 14%. 1.5 m 로 넓히면 허용하중을 34% 넘는다. 40 kN 은 극한값이라 허용하중으로 쓰면 안 되며, 제품 성적서 값이 더 작으면 그 값을 넣는다 [입력].

### S10 RAVA3Pro 프리캐스트 중공 슬래브 — 부정 시험 — 미실행

판정 엔진이 아니라 Revit 요소 인식(ZoneGenerator) 단계의 시험이라 이 스크립트로는 돌릴 수 없다. 합격 기준: 생성 0, 한국어 안내('구조 바닥이 있는 레벨을 찾지 못했습니다…').

### S11 센서 구역 최소가 날짜 사이클을 덮어씀 — PASS

날짜 사이클만 보면 9층은 12/30 에 끝나지만, 북측 그늘 구역은 센서 구역 최소 강도가 기준에 닿는 날까지 존치다 (v6: 실제 타설·공시체·센서 기록만으로 판정 — 공정 계획 반영은 공정 계산과 함께 뺌).
