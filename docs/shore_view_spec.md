## 0. 지금 있는 것 (그대로 씀)
- 구역 선택 강조(ZoneFocus·ZoneLabels DirectContext3D 덧그림 — 모델·실행 취소 목록 안 건드림), 동바리 표시 4가지(선택 구역만 / 판정 대상 층만 / 전부 / 숨김), [같은 층만].
- 4D 미리보기(FourD·Timeline): **계획** 공정(SHORE_INSTALL·REMOVE) 기준으로 동바리가 나타났다 사라짐, 색 = 구역 판정 상태, 층 따라가기 카메라, 층별 공정 막대.

## 1. 빈 곳
1. 동바리를 만든 직후 "만든 동바리"를 바로 볼 화면이 없음 (생성 결과는 결과 창 글뿐).
2. 동바리 **자체**의 상태(설치 검측 OK·NG·필요 / 서 있어야 함 / 해체 요청 가능 / 감리 확인 / 해체됨 / **무단 해체 의심**)로 칠하는 보기가 없음 — 지금 색은 구역 판정 상태.
3. 4D 는 계획 공정만 — 실제 기록(동바리 확인·협력업체 신고·승인 기록)으로 "그날 실제로 서 있던 동바리"를 못 봄. 동시 본수 곡선(임대 비교)이 4D 와 따로 놂.

## 2. 만들 것 (모두 결과물 파장 — impact_map #24)
### V1 [생성 결과 보기] — 동바리를 만든 직후
- [구역·동바리 생성] 끝나면 결과 창에 [생성한 동바리 보기] 버튼 → "Revit On-Site 동바리" 3D 뷰(없으면 만듦, 검측 뷰 복제): 단면 상자 = 이번에 만든 층들 + 1 m, 그 층 동바리만 보이게(다른 층 동바리 숨김), 슬래브·벽은 반투명 60 % [가정]·회색, 구역 상자 숨김.
- 덧그림으로 동바리 강조: 층마다 색 하나(층 구분), 결과 창 숫자(층별 본수)와 같은 숫자를 뷰 왼쪽 위 글자로.
- 뷰 설정만 바꿈(트랜잭션 하나, 이름 "동바리 보기"), 동바리·모델 값은 그대로.

### V3 동바리 타임라인 (4D 에 '동바리' 보기 추가)
- 4D 재생에 보기 고르기 [건물 / 동바리]: '동바리'면 슬래브는 윤곽만, 동바리만 보이며 색 = V2 상태를 **그날** 기준으로(계획 + 그날까지의 실제 기록 — 실제 기록이 있으면 실제가 이김, 화면에 '계획'/'기록' 구분 표시).
- 공정 막대 아래 **동시 동바리 본수 곡선**(plan_cost.daily 와 같은 계산, 실제 기록 반영 선 + 계획 선, 보유 본수 [입력] 가로선) — 재생 막대와 같은 시간축, 지금 시각 세로선. 보유 본수를 넘는 구간은 빨강 띠("조기 해체 압력").
- 무단 해체 의심이 생긴 날에 막대 위 ■ 표지, 누르면 그날로 이동.
- 날짜별 뷰 저장(기존)에 '동바리' 보기도 저장.

### V4 시공 순서가 보이는 타임라인 (사용자 추가 요청 11-05)
사용자 원문: "타임라인뷰로 조회될 때에는 동바리가 지어지고 그 다음에 타설되고 지어지고, 벽체와 같은 경우에는 거푸집이 지어지고 그 다음에 타설되고 해체되고 이런 과정이 보여져야겠지, 기존 부재가 부착된 상태로 유지되는 게 아니라".
- **원칙: 아직 시공 안 된 부재는 안 보임**. 기존 모델 부재(슬래브·벽·기둥·보)를 그 층 공정 전에는 숨기고, 단계마다 '공사 중 모습'(덧그림)으로 바꿔 보이다가 끝나면 실제 부재를 보임.
- 층 N 한 사이클(국내 공동주택 알폼 벽·슬래브 일체 타설 [가정], 사이클 일수 = 프로젝트 설정):
  1. **벽·기둥 거푸집 설치** — 벽·기둥 자리에 거푸집 판(벽 양면 얇은 판, 합판·알루미늄 회색) 덧그림, 실제 벽은 숨김
  2. **동바리 설치** (기존 SHORE_INSTALL) → 설치 검측 → **슬래브 거푸집·철근**(기존)
  3. **타설** (pours.csv 날짜·시각, 기존 타설 진행 조각) — 벽·기둥도 같은 시각에 콘크리트로 채워짐(일체 타설 [가정]; 벽 따로 타설 자료가 있으면 그 날짜)
  4. **벽·기둥 거푸집 해체** — 타설 다음 날 [가정](벽 거푸집 존치 기간은 KCS 14 20 12 측면 거푸집 기준 — 출처 확인 전 [가정] 1일, 설정 값) → 거푸집 판 사라지고 실제 벽·기둥 보임
  5. **슬래브 동바리 해체** (기존 SHORE_REMOVE / V3 기록) → 동바리 사라지고 실제 슬래브 보임
- 벽·기둥 구분: 모델에서 층(Level)·구조 여부로 그 층 벽·기둥을 모음(ShoringModel 이 이미 슬래브를 찾는 방식과 같게), 비구조 벽(칸막이 등)은 [가정] 마감 공정이라 마지막(동바리 해체 뒤)에 보임 — 판단 맡김.
- 계획 공정에 벽 단계가 없으면 schedule.py 의 층 사이클에서 위 상대 일수로 만듦(Python 기준 먼저 — 공정 코드 WALL_FORM·WALL_STRIP 추가, 기존 코드·결과 바이트 그대로).
- 웹 4D(onsite_4d.html)도 같은 순서(벽 거푸집 → 타설 → 해체)로 — export_4d 에 벽 단계.

### S 단계 해체·조기 탈형 구조 검토·동바리 재사용(전용) (사용자 요청 11-05 09:0x)
사용자 원문: "동바리의 단계 해체와 관련해서는 구현되지 않았는데 이 조기 탈형의 구조적 검토와 합당성, … 동바리를 재사용하는 것과 관련된 논문(ACI PRC-347.2 Shoring/Reshoring)에 착안하여 동바리 재사용 검토 … 벽체가 지어지고 그 다음에 조기 탈형이 가능하다면 이뤄지는 그런 느낌이 보여야".
근거(이미 저장소에 [확정]): `shoring/regulation_check.md` §7 — 측면(벽·기둥) 5 MPa, 무시험 일수(평균 ≥ 20 ℃ 보통 4일 / 10–20 ℃ 6일), 필러 존치 판넬 조기 탈형 = 14 MPa + 구조검토 + 책임기술자 승인 (가이드라인 p10 (2)①: **필러 동바리 전체 존치**), KCS 3.3.1(5) 10 ℃ 이상 4일 이상. ACI 347.2 는 본문 미확인 → **개념(재받침·전용 일정)만, 숫자는 우리 계산**.
- **S1 벽 거푸집 해체일** = 구역 추정 강도가 5 MPa 에 처음 닿는 날(엔진 예측·센서) 과 무시험 일수(그 기간 평균기온) 중 판정 근거 있는 쪽 — 둘 다 표시, 이른 쪽은 '시험 확인 시'. V4 의 WALL_STRIP 날짜는 이 값.
- **S2 단계 해체 (구역마다 3단계)**: ① 판넬(거푸집 널) 탈형 — 필러 전체 존치, 조건 4개 모두: 추정·공시체 최소 ≥ 14 MPa · 10 ℃ 이상 4일 양생 · 위층 하중비교(기존 load_check, 그날 강도) ≤ 1.0 · '구조검토서·책임기술자 승인' 근거 원장 기록(없으면 '필요') → "판넬 탈형 요청 가능 (필러 존치)" ② 필러 동바리 해체 = 지금 판정 게이트(fck·3개층·지지층) ③ 재받침(필요할 때, 기존 상태 8). 결론 문구는 '요청 가능 / 존치 / 필요'까지.
- **S3 조기 탈형 구조 검토서(초안)**: 구역마다 한 장 — 그날 강도(근거), 14 MPa·4일·하중비교 계산(식·값·출처 쪽수), 필러 배치 = 모델 동바리 전체(본수), 서명란 빈칸(책임기술자). 검측요청서와 같은 '초안·승인 아님' 문구.
- **S4 동바리·판넬 전용(재사용) 계획**: 층 N 판넬이 ①에서 빠지는 날 ≤ 층 N+1 슬래브 거푸집 시작일이면 그 판넬을 N+1 로 돌림(전용), 필러는 ②에서 빠지는 날 ≤ 층 N+k 동바리 설치일이면 전용. 층마다 "어디서 온 판넬·동바리인지", 모자라면 추가 세트. 비교 2가지: ⓐ 단계 해체 없음(판넬·동바리 같이 존치) ⓑ 단계 해체(판넬 조기 전용) — 필요한 판넬 세트 수·동바리 세트 수·마지막 해체일. 비용은 costs.csv 단가 있을 때만. 임대 계획 비교(plan_cost)와 같은 동시 본수 계산을 재사용.
- Python 기준 `shoring/staged.py` 새 파일(하위 에이전트) → 작업 세션 C# 이식 + 판정표·대시보드·검측요청서에 단계 ① 결과 줄, [임대 계획 비교]에 ⓐⓑ, 새 결과물 `조기탈형검토서_YYYYMMDD.html`·`전용계획_YYYYMMDD.html`.

- **지금 일어나는 일 강조**: 그날 단계가 바뀐 부재만 밝게 테두리·잠깐 깜빡(0.5 s), 나머지는 차분한 색. 단계 색표(벽 거푸집·동바리·판넬·철근·타설·필러만 남음·해체됨) 범례 칩.
- **필러만 남은 상태가 보임**: 판넬 탈형 뒤 슬래브 아래는 동바리(필러)만, 판넬 판은 사라짐.
- **전용 화살표**: 판넬·동바리가 아래층에서 빠져 위층으로 갈 때 짧은 곡선 화살표(덧그림, 1 일 표시) + 막대 위 '전용 n본'.
- 재생: 하루 단위 ◀ ▶ 한 칸, 속도 3단, 사건(타설·탈형·해체·무단 해체 의심) 사이 건너뛰기, 카메라 = 지금 공사 층 따라가기(기존) + 그 층 확대 버튼.
