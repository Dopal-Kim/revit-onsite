## 잘 된 점 3줄
1. 판정 근거 창은 비교 줄만("공시체 25.1 ≥ 24.0 ✓ · 존치 층수 3 ≥ 3 ✓ · 지지층 … ≥ 14 ✓ · 하중비 0.83 ≤ 1.00 ✓")이라 공무가 감리에게 말로 설명할 문장이 그대로 나옴.

3. 휴대폰·[구역 정보]·PC 입력 창이 같은 검사·같은 문구라 어디서 넣어도 결과가 같고, [구역 정보] 한 창에서 구역 하나의 사양·타설·공시체·센서·설치 검측을 다 봄.

## 가장 큰 문제 5개
1. **같은 날 같은 데이터인데 서류마다 '요청 가능' 숫자가 다름** — 대시보드 4구역, 검측요청서·패키지 6구역, 슬래브 이력서 머리 31구역. 감리가 서류끼리 대조하면 바로 신뢰가 깨짐 (#1).
2. **현장 확인 3가지가 전부 ✕ 인데도 검측요청서가 '요청 가능'으로 나감** — 5F 6구역 모두 근거 1/8, 작업계획서·해체 전 체크리스트·위 3개층 확인 없음. 가이드라인 3.2 순서(계획서 → 감리 확인 → 체크리스트 → 감리 확인)를 건너뛴 요청서가 됨 (#2).
3. **잘못 넣은 타설·공시체·사양을 고치려면 데이터 폴더 CSV를 직접 고쳐야 함** — 현장에서 날짜 오타는 흔한데, 고칠 방법이 엑셀뿐이고 해시 사슬 파일 옆이라 위험 (#6).
4. **'시험 필요'가 두 뜻** — 대시보드 칩 "공시체 시험 필요 0구역" 바로 위 '오늘 볼 것'에 "시험 필요 19" (#3).
5. **동바리 허용하중(제품 성적서 값)을 넣는 칸이 없음** — 설치 검측 1본 하중은 기본 13.3 kN으로 검사, 제품 값은 Revit 속성 창 매개변수로만 바꿈. 감리가 조립도·성적서와 대조하는 핵심 값이 입력 창에 없음 (#10).
