Revit On-Site 빠른 시작 동바리 타설·해체 검측 · 1쪽 공무·BIM 담당 (Revit) · 2쪽 휴대폰(품질·안전관리자 / 협력업체 반장)·동바리 보기·단계 해체·감리

버튼은 모두 리본 Revit On-Site 탭에 있습니다 — 패널 순서 = 업무 순서: 준비 → 설치 검측 → 타설·데이터 → 판정 → 승인 → 보고·공유 → 타임라인. 버튼 위에서 F1 = 도움말 그 항목. 결과물은 [프로젝트 설정]의 데이터 폴더에 남고 YYYYMMDD = 마지막 판정 기준일.

결론은 "해체 승인 요청 가능" / "존치", "타설 요청 가능" / "타설 보류"까지입니다. 프로그램은 해체·타설을 지시하거나 승인하지 않고, 요청서 서명란은 비어 있습니다 — 해체 여부는 감리 확인·서명을 거쳐 현장 책임자가 정합니다.

공무·BIM 담당 — 프로젝트 시작할 때 한 번

  1. Revit 옵션 › 색상 › 캔버스 테마 = 밝게 (상태 색이 대시보드와 같게 보임)
  2. 준비 › 프로젝트 설정 — 첫 타설일(착공일 아님)·사이클·최소 존치 층수·배합·fck·양생 최저 온도·기상 관측소·데이터 폴더 (선택: 예측일에 현장 보정 쓰기 · 층 높이 보정 쓰기)
  3. 준비 › 매개변수 연결 → 준비 › 뷰·필터 준비 → 준비 › 모델 진단 (IFC 모델이면 꼭) → 준비 › 구역 나누기(열 때 확인 창으로도 — 구역만) → 동바리 › 층 입력 뷰에서 놓기·구역 이동·구역 해체·3개층 확인
  4. 날짜는 직접: 동바리 세운 날 동바리 › 동바리 사양(설치일), 타설한 날 타설·데이터 › 타설 등록 (v6 — 공정표 가져오기 없음)
  5. 층마다 동바리 설치 뒤 설치 검측 › 설치 검측 — 설치 서류는 승인 › 근거 원장 1 설치검측

주간·필요할 때

  • 타임라인 › 강도 타임라인 — 층별 추정 강도(참고)가 14 MPa·fck 에 언제 닿을지, 그날까지 공시체 실측
  • 보고·공유 › 슬래브 이력서 → 슬래브이력서_YYYYMMDD.html·.csv · 보고·공유 › 품질 대장 → 품질대장_YYYYMMDD.html
  • 보고·공유 › IFC 내보내기 → RevitOnSite_YYYYMMDD.ifc (+ _근거.csv·_Pset.txt) · 보고·공유 › 웹 공유판 → <모델 이름>_4d.html · 승인 ▾ › 감사 기록 → 감사기록_YYYYMMDD.csv

센서가 없어도 됩니다 — 현장양생 공시체 + 기온만으로 판정·요청서·승인 기록·타설 전 확인이 모두 동작합니다(센서는 구역 안 가장 낮은 강도를 더하는 위치 근거).

품질·안전관리자 — 휴대폰 (현장 입력)

여는 법: 현장 PC 의 현장 입력 창 [현장 입력] 탭 QR 을 휴대폰 카메라로 찍습니다 (현장 PC 와 같은 Wi-Fi). 주소는 12시간 뒤 만료 — PC 에서 새 주소. 입력자 이름은 처음 한 번.

순서: 층 → 구역 타일(색 = 지금 판정) → 측정 종류 → 값 → 저장. 저장하면 그 구역의 판정과 사유가 바로 보입니다.

측정 종류언제넣는 것판정에서
공시체 (현장양생)시험한 날구역·시험일·양생 방법·강도 3개 MPa (채취 정보는 선택)기준 근거 — 없으면 "공시체 시험 필요"
온도 / 강도 센서매일 또는 센서 앱 기록 붙여넣기센서 ID·위치·시각·값위치 근거 (구역 최소)
반발경도필요할 때구역·위치·R 값참고만
동바리 확인다음 층 타설 전·매일구역(그 아래 동바리)·확인 시각·지금 서 있나 예/아니오 · 사진 1장(선택)타설 전 확인 (최근 24 h '예' [가정])
해체 후 점검해체 뒤점검일·5항목 예/아니오 (하부 3개층·상하 정렬·연직도·자재 변형·콘크리트 면) · 사진 1장참고 — 근거 원장 8 결과보고와 묶음
동바리 점검설치 뒤·매일·해체 전·해체 후단계 → 항목 OK/NG (전부 OK, NG 로 고른 항목은 그대로) → NG 면 구역 평면에서 문제 동바리를 눌러 여러 개 (두 손가락 확대) · 사진 없음 · 이름 구역-R행C열설치 검측 NG 미해결 → "존치 (설치 결함 기록)"·"타설 보류" (다시 OK 면 풀림), 다른 단계 = 기록·Revit 빨강
  • 사진: 원본 그대로 데이터 폴더 사진\YYYYMMDD\{구역}_{종류}_{시각}_{해시}.jpg 에 저장되고 해시(SHA-256)가 기록에 남습니다 — JPEG·PNG, 8 MB 이하 [가정].
  • 전파가 약하면: 기록은 휴대폰에 "기기에만 저장 · 시각" 으로 남고 연결되면 자동으로 보냅니다(같은 기록은 한 번만). 사진은 기기에 3장까지 [가정] — 넘으면 "사진은 연결된 뒤 다시".
  • 맨 위 오늘 볼 것: 무단 해체 의심 → 타설 보류 → 시험 필요 → 상태 바뀜 → 입회 없음 — 눌러서 그 구역으로.

협력업체 반장 — 해체 신고 QR

  1. 현장 담당자가 보여 주는 신고 QR(층마다)을 찍습니다. 층 표지에 붙은 QR 은 보기 전용(신고 안 됨).
  2. 이름(필수)·소속(선택)은 처음 한 번. 사진을 붙이려면 사진 칸에서 찍습니다(1장, 다음 신고에 붙음).
  3. 동바리를 뺀 구역에서 이 구역 동바리를 뺐음, 다시 세웠으면 다시 세움 → 확인 창에서 [확인].
  4. 화면 문구: "신고 저장됨 — 감리 승인 기록 있음: 해체 시각 기록됨" 또는 "… 감리 승인 기록 없음: 현장 확인 요청됨"(현장 담당자에게 알림이 갑니다).
  5. 지하처럼 전파가 약하면 "기기에만 저장" — 연결되면 자동 전송, 기록 시각은 서버가 받은 시각.

층 화면의 "해체 금지 — 존치", "해체 금지 — 감리 확인 전 (해체 승인 요청 가능)" 는 판정 기록을 옮긴 것입니다. 해체 여부는 감리 확인을 거쳐 현장 책임자가 정합니다.

  • 판넬 단계: 판정 근거 창 ①–④ → 보고·공유 › 조기 탈형 검토서(초안) → 책임기술자 서명 → 승인 › 근거 원장 구조검토서 → 판넬만 탈형(필러 존치)

감리에게 가는 것

  • 해체 검측요청서 해체검측요청서_YYYYMMDD.html — A4 4쪽 서식(요청서·결과 통보 / 근거표 / 4.1·4.2·4.3 체크리스트 / 실명부) 인쇄·PDF, 서명·결과·합불 칸 빈칸. 현장 확인 ① 위 3개층 동바리 존치(최근 24 h) ② 작업계획서 ③ 해체 전 체크리스트, 마감 값 8자(서명 종이에 적어 대조).
  • 검측 패키지 검측패키지_YYYYMMDD\ — 요청서·이력서·감사 기록·근거 원장·첨부(현장 사진 포함)를 한 묶음으로, 목록.csv·index.html 에 파일마다 SHA-256 (받은 쪽이 다시 계산해 같으면 보낸 그대로).
  • 층 표지 층표지_YYYYMMDD.html — 층 입구 게시, QR = 보기 전용 층 화면.
  • 서명 뒤: 공무가 승인 › 승인 기록 에 감리 승인 기록(서명한 감리 성명·일시)을 남깁니다.
  • 강도 타임라인으로 설명 듣기: 공무가 타임라인 › 강도 타임라인 사건 ▶| 로 층 타설 → 추정 14 MPa·fck 도달(참고) → 공시체 시험 날을 차례로 보여 줌. 판정은 공시체 실측.
