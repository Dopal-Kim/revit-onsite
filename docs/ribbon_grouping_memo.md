# 리본 ▾ 묶음 후보 (v6.2 W13 — 발표 뒤 처리, 총괄 결정 11-09)

이번 87차 묶음에서는 **리본을 바꾸지 않는다.** 발표 가이드 스크린샷 33장·도움말·회귀 절차(docs/regression_check.md)가 지금 버튼 위치 기준이라서다. 대시보드 쪽 '오늘 할 일' 줄(① 판정 → ② 오늘 볼 것 → ③ 요청서 → ④ 층 표지)과 역할 보기만 넣었다.

발표(11-18) 뒤 다시 볼 후보. 기준은 "날마다 누르는가": 날마다 누르면 큰 버튼으로 그대로 두고, 프로젝트를 시작할 때 한 번 또는 가끔 누르면 ▾ 안으로 넣는다.
