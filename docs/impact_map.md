# 기능 → 결과물 → 산업 파장 지도 (기준표 · 계속 고침)

**이 표가 모든 기능 결정의 기준이다** (사용자 지시 11-05 — 가장 중요). 새 기능은 먼저 여기에 한 줄을 쓴 뒤 만든다. ② 오류 검토와 **별도로** ⓐ 기능 적합성 검사 사이클을 이 표로 돈다.
근거 숫자는 `docs/문제정의_방향성.md` 2절·`docs/direction_review_20261104.md` 에서만. 태그 [확정]/[부분 확인]/[가정]/[미확인].

## 0. 한 줄
지금 현장은 동바리를 **날짜 사이클**로 빼고, 협력업체가 뺀 사실은 **기록에 안 남는다**(화정 1심 [부분 확인]). Revit On-Site 는 해체·타설 판단을 **근거가 붙은 결과물**(판정표·검측요청서·층 표지·근거 원장·IFC)로 바꿔, "몰랐다"가 통하지 않는 현장 기록 체계를 만든다 → 안전(붕괴 경로 차단 신호)·품질(슬래브 이력)·책임(해시 사슬)·제도(현장양생 공시체 의무화 이행 도구, 검단 권고 "검측 자료 디지털화·BIM 활용").
