## 1. 공정표 제거 → 날짜 두 개 직접 입력 (담당: 작업 세션)
- 입력: 층(구역)마다 **동바리 설치일**(새, 데이터 폴더 `shore_installs.csv` [제안]) + **타설일**(기존 [타설 등록] pours.csv).
- 강도 추정(참고) = 타설일 + 날씨(weather.csv) + 층 높이 보정 [가정: 기온감률 0.65 ℃/100 m + 노출 보정 작게, 값은 [프로젝트 설정]에서 끄고 켬].
- 제거(리본·코드·시험, 파일은 휴지통): 공정표 가져오기(CmdImportSchedule·schedule.py 의존), 재계획(CmdReplan), 임대 비교(CmdPlanCost·plan_cost), 날짜 뷰 저장(CmdSaveViews), 공정표 기반 4D 시공 순서(벽 거푸집·창호·철근 단계), 전용 계획(CmdReusePlan — 다음 층 예정일 의존), 공정 KPI(계획 대비).
- 유지·변경: 단계 해체 검토(조기 탈형) = 실제 입력 날짜 기준. 예측 해체일 = 추정 곡선이 기준에 닿는 날(참고).

## 2. 동바리 입력 탭 (담당: 작업 세션, 1 끝난 뒤)
- 리본 [동바리] 패널: 층 버튼 → 그 층만 보이는 평면 입력 뷰('Revit On-Site 동바리 입력 – nF', 크롭·다른 층 숨김).
- 사양 입력 창(그 층에 현장 정보 없으면 먼저 뜸): 종류(파이프 서포트/시스템 동바리), 규격, X·Y 간격 mm, 이음 수, 설치일 → 데이터 폴더 `shore_spec.csv` [제안]. 탭에서 언제든 조회.
- 놓기 도구: 한 본 놓기 · 줄로 놓기(두 점+간격) · 구역 채우기(입력 간격) · 도면(CAD)에서(링크 DWG 의 원·블록 중심, 시간 모자라면 맨 뒤로) · 위층으로 복사 · 기존 부재(파이프·기둥)를 동바리로 등록.
- 구역 단위: 구역 고르기 → 그 안 동바리 한꺼번에 이동 / 해체(모델에서 삭제 + 위치·날짜를 `shore_removed.csv` 기록, 휴대폰·보고서 이력 유지).
- 3개층 확인 표: 층마다 설치·해체 본수 누적, 아래 3개층 비면 빨강.
- 기존 자동 생성 = 이 탭 안 '예시로 채우기' 한 버튼으로 강등.
- 패밀리·매개변수: 기존 SHR_PipeSupport + 기존 SHR_* 만 (SHR_GenBy = "입력" 등). 새 공유 매개변수 없음.

## 3. Vercel 서버 (담당: vercel 세션, 1·2 와 병행)
- `server/vercel/`: 정적 = 사용자 수정본 `현장입력_수정본.html`(미리보기 가짜 서버 블록 제거) + `view.html`. API = 기존 field_server 와 같은 주소·응답(/api/model, /api/floor, /api/recent, /api/measure, /api/report) + Revit 동기화(/api/sync/push 스냅샷, /api/sync/pull 입력 가져가기·확인). 저장 = Vercel Blob. 토큰: 입력 t·보기 v·신고 r·Revit 쓰기 키 — 환경 변수, 저장소에 비밀 금지.
- 판정은 Revit 만: 휴대폰 저장 답 = "저장됨 — 판정은 다음 동기화 뒤 반영". 입력 검사는 field_server.validate() 를 JS 로 같은 문구로.
- Python 동기화 클라이언트 `tools/server_sync.py`(push: Store.model()/floor_view 스냅샷, pull: 입력 → CSV, client_id 중복 없음) + 시험. C# 토글은 작업 세션이 이식.
- 와이파이(LAN) 서버는 지하·무인터넷 예비로 유지.
- 배포: 사용자 승인됨("바로 서버 열고"). Vercel 로그인은 사용자가 직접.

### 1. 열면 바로 구역 (담당: 작업 세션)
- 모델을 열거나(DocumentOpened) Revit On-Site 탭 버튼을 처음 누를 때, **구조 슬래브(현장타설)가 있고 구역이 0개**면 확인 창 1번: "층 n개 · 구역 기준(그리드/기둥열/타일) · 예상 구역 m개 — [구역 나누기] [나중에]". 모델을 바꾸므로 묻는다 [총괄 결정]. [나중에] = 그 문서를 닫을 때까지 다시 안 물음.
- [구역 나누기] 한 번에: ① 기존 SHR_·SNS_·PRJ_ 매개변수 연결(새 공유 매개변수 없음) ② 프로젝트 설정 기본값 자동(데이터 폴더 = rvt 옆 `onsite_data_<파일이름>`, 나머지 기본값 — 사용자가 [프로젝트 설정]에서 나중에 고침) ③ **구역만** 생성(동바리 0) ④ 결과 한 줄("구역 m개 · 층 n개 — 이제 [층 입력 뷰]에서 동바리를 놓으세요").
- 대상 슬래브 없음(프리캐스트·목조 등, RAVA3Pro): 창 대신 안내 한 번 "동바리 대상 구조 슬래브 없음 — [모델 진단]에서 이유 보기". 오류·멈춤 없음.
- 리본 [준비]에 [구역 나누기] 버튼(다시 나누기). 다시 나눌 때 **직접 놓은 동바리(SHR_GenBy=입력·CAD·기존 부재)는 지우지 않고 위치로 SHR_ZoneID 를 새 구역에 다시 매김**, 어느 구역에도 안 들어가면 목록으로 알림. 데이터 폴더 CSV 의 옛 구역 ID 가 새 구역에 없으면 경고(자동 변경 금지).
- [예시로 채우기]는 그대로(구역 + 예시 동바리).

- **W7 워크셰어링·동시 쓰기**: `doc.IsWorkshared` 면 매개변수 쓰기 전 `WorksharingUtils.GetCheckoutStatus` — 다른 사용자 소유 요소는 건너뛰고 결과 창에 "n개 — 소유: 이름" 목록(판정 결론은 CSV·eval_log 에 그대로 남김). 데이터 폴더 CSV 이어 쓰기 = 잠금 파일 + 짧은 재시도, 실패 시 이유 문장(자료 손실 금지). 네트워크 경로 데이터 폴더 허용.
- **W9 순찰 확인**: 동바리가 있고 '해체 완료'가 아닌 구역은 `patrol_hours`(options.json, 기본 24 [가정]) 안에 동바리 확인(shore_checks — 안전관리자 확인·사진 포함) 이 없으면 오늘 볼 것 "순찰 확인 없음" (무단 해체 의심·타설 보류 다음 순서). 판정 결론은 안 바꿈.
- **W10 층 표지 유효 시간**: 표지 머리에 인쇄 시각 크게 + "인쇄 후 n시간[가정 24] 지나면 QR 화면으로 현재 상태 확인". QR 주소에 인쇄 시각 포함 → 서버 층 화면이 "표지 인쇄 후 n시간 · 표지와 지금 상태 다른 구역 m개" 띠(S2 와 같이).
- **W11 범위 밖 알림**: slab_mm > `scope_slab_max_mm`(options.json, 기본 300 [가정]) 또는 지하층(레벨 높이 < 0) 또는 동바리 높이 5 m 이상 구역은 ⚠ "범위 밖 가능 — 구조기술자 검토 (재받침·층간 하중 분배 미계산)" 줄. 결론 문구는 그대로, 요청서 현장 경고·판정 근거·[구역 정보]에 표시(최상층 [가정] ⚠ 와 같은 방식).
- **W12 시공하중 문구**: 조기 탈형 검토서·판정 근거의 하중 줄에 "시공하중 2.5 kN/m² [가정] — 자재 적재·장비 집중하중 미반영" + [프로젝트 설정]에서 값 변경(이미 있으면 표기만).
- **W-A Revit 쪽 동기화**: push 스냅숏에 강도 타임라인 자료(export_4d / StrengthTimeline 이 쓰는 층별 곡선·구역 색·판정·오늘 볼 것) 추가. pull 에 감리 직접 승인(S3) 받아 `approvals.csv` "감리 승인 기록"(approver·signed_at = 서버 시각, `source=감리 직접`) — 기존 approval 검사(그 시점 판정 '해체 승인 요청 가능' + 요청 제출 있음) 통과 못 하면 넣지 않고 '오늘 볼 것'에 이유. 종이 서명 경로는 `source=종이 옮김` 으로 남기고 이력서·감사기록에 두 출처를 구분 표기(검측요청서는 승인 전 서류라 해당 없음 — 11-09 명세 정정).
- **W13 (UI 단계, 맨 끝)**: 대시보드 맨 위 '오늘 할 일' 순서(판정 → 오늘 볼 것 → 요청서 → 층 표지)와 역할 보기(공무/안전/품질 — 해당 버튼·줄만). 리본은 자주 안 쓰는 버튼을 ▾ 묶음으로. 기능 동작은 바꾸지 않음.
