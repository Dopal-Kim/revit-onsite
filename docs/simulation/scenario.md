# 현장 시뮬레이션 시나리오 (초안 — 실행은 '안정화 관문' 통과 뒤)

사용자 지시(11-05): "레빗 프로젝트가 잘 구동되면, 그 구동 파일로 실제 건물을 지어가는 과정의 시뮬레이션 → 어떤 절차대로 쓰는지 가이드라인 + 시뮬레이션 보고서, 너무 복잡하지 않게, PDF, 실제로 따라 해 보기 적합하게." / "전제는 프로젝트가 안정화되고 기능이 정상 작동한다는 가정 — 일단 완성도에 집중."

## 안정화 관문 (이것을 통과해야 시뮬레이션 실행)
1. `tools\run_all_checks.py` 전부 통과 (Python + C# 일치)
2. **전체 회귀 화면 점검 2회 연속 실패 0** — 핵심 흐름(아래 시나리오 1–10단계와 같은 버튼)을 최신 빌드로 끝까지
3. KBIM 사본에서 판정·4D·동바리 보기가 오류 없이 열림
4. 남은 결정 대기(공유 매개변수·3개층 본수·기상청 키)는 시나리오에 영향 없음을 확인 (영향 있으면 사용자에게 먼저)
