# Revit On-Site 시연 영상 대본 (v9 · 2분 7초)

영상 파일: `RevitOnSite_시연_v9.mp4`
- v8에서 구조도(Revit · 서버 · 휴대폰)를 뺐습니다. 발표 초반에 이미 다루기 때문입니다. 그 자리에 층마다 동바리를 입력하는 과정을 넣었습니다.
- 흐름: 동바리 입력 → 휴대폰 공시체 입력 → 판정 → 요청 제출 · 검측요청서 출력 → 감리 승인 기록 → 층 표지.
- 음성은 없고 자막과 효과음만 들어 있습니다. 아래는 발표 때 영상에 맞춰 읽는 말입니다.
- 화면의 QR은 로컬 시연 서버의 시험 토큰입니다. 실제 Vercel 토큰은 들어 있지 않습니다.

| 시간 | 화면 | 대본 |
|---|---|---|
| 0:00 | 제목 | Revit On-Site를 실제로 쓰는 흐름입니다. 동바리 입력부터 보겠습니다. |
| 0:04 | 층 입력 뷰 | 리본에서 층 버튼을 누르면 그 층만 보이는 '동바리 입력' 평면이 열립니다. 다른 층이 겹쳐 보이지 않아서 헷갈리지 않습니다. |
| 0:09 | 동바리 사양 | 층마다 종류, 규격, X · Y 간격, 이음, 설치일을 한 번 넣습니다. 공정표를 따로 맞출 필요 없이 설치일을 직접 넣고, 넣은 간격이 그대로 놓는 간격이 됩니다. |
| 0:13 | 놓기 메뉴 | 놓는 방법은 여섯 가지입니다. 한 본씩, 줄로, 구역 채우기, 위층에서 복사, 도면(CAD)에서, 기존 부재 등록. 시공사 배치도 DWG가 있으면 도면에서 그대로 가져옵니다. |
| 0:18 | 구역 채우기 | 보통은 구역 하나를 사양 간격 격자로 한 번에 채웁니다. 10F-B1은 900 × 1200 mm 격자로 77본이 한 번에 놓였습니다. |
| 0:23 | 3개층 확인 | 다 놓으면 3개층 확인을 누릅니다. 층마다 설치 · 해체 · 지금 본수가 나오고, 타설층 아래 3개 층이 비어 있으면 빨갛게 표시됩니다. |
| 0:27 | [서버 연동] QR → 휴대폰 | 타설 뒤에는 품질관리자가 QR을 찍어 휴대폰으로 입력합니다. |
| 0:33 | 휴대폰 공시체 입력 | 층과 구역을 고르고 공시체 강도 세 개를 넣습니다. 한 번 뜬 공시체는 같이 타설한 여섯 구역 모두의 근거가 됩니다. |
| 0:48 | 서버 취합 · 웹 4D | 저장한 값은 서버에 바로 모이고, 아직은 '판정 전'으로 보입니다. |
| 0:55 | 5분 뒤 · Revit 동기화 | Revit이 5분마다 입력을 가져가 판정하고 결과를 다시 올립니다. |
| 1:11 | 층 표지 QR → 반장 신고 | 동바리를 뺀 반장이 층 표지 QR로 그 자리에서 남깁니다. |
| 1:23 | 서버 즉시 빨강 | 승인 기록 없이 뺐으면 서버가 바로 빨강으로 띄웁니다. |
| 1:27 | Revit 대시보드 · 판정 | 공무는 하루 한 번 판정을 누릅니다. 결론은 '해체 승인 요청 가능' 아니면 '존치'입니다. |
| 1:34 | 승인 기록 창 · 요청 제출 | 요청 가능이 나온 구역은 '요청 제출'을 고르고 입력자와 메모를 남깁니다. |

| 1:43 | 조기 탈형 검토서 | 판넬만 먼저 떼려면 네 가지 조건이 붙은 검토서 초안을 뽑습니다. |
| 1:47 | 감리 휴대폰 확인 | 감리는 요청 구역을 휴대폰으로 열어 세 가지를 체크하고 승인 기록을 누릅니다. |
| 1:55 | 감리 휴대폰 · 승인 기록 누름 | 기록은 '감리 직접'으로 남고, 그사이 판정이 바뀌었으면 넣지 않습니다. |
