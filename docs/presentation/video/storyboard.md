# Revit On-Site 사용 가이드 시연 영상 — 스토리보드 (v6.2, 11-09)

사용자 요청(11-09): 가이드라인(발표 가이드 슬라이드)을 따라가는 시연 영상. QR 입력은 QR 창을 띄우고 → QR 화면을 왼쪽에 따로 띄우고 → 점선 직사각형이 화면을 투영하듯 오른쪽으로 펼쳐져 어떤 인터페이스에서 어떤 입력을 하는지 보여 줌 → 서버(HTML)로 전송·취합 → 4D(강도 타임라인)로 조회되는 과정.

## 참고한 시연 영상 원칙 (조사 11-09)
- 한 영상 = 한 업무 흐름. 문제 → 약속 → 3–5개 장면(행동 + 결과) → 결과 화면에서 멈춤.
- 장면마다 짧은 자막 한 줄(6단어 안팎), 조작 중인 UI 를 가리지 않는 자리.
- 작은 값·입력 칸을 읽어야 할 때만 1.5–2× 확대 → 잠깐 멈춤 → 원래 크기. 화면 이동 중에는 확대하지 않음.
- 클릭 위치는 설명 박스·화살표가 그 단어와 같은 때 나옴. 휴대폰은 손가락 대신 탭 표시(원 파문).
- 기다리는 시간(로딩·동기화 5분)은 잘라 내고 "5분 뒤" 카드로.
- 도움말형 영상: 꾸밈 적게, 화면 그대로, 단계 표지(STEP n · 패널 › 버튼)로 위치를 알려 줌. 음악 없음(반복 시청).
- 출처: Viditor·OpenScreen·Moonjar·SmoothRecorder 데모 영상 가이드(2026), Autodesk Build 모바일 시연(구성 참고).

## 형식
1920×1080, 30 fps, 약 5분, 한국어 자막(본문 Noto Sans KR), 색은 발표 pptx(동바리최대한짧은버전) 테마와 같음 — 남색 #1B2A41 · 바탕 #EEF3F9 · 강조 파랑 #1F5FA8/#799FCB · 회청 #4A5D75 (11-09 사용자 요청으로 주황 → 파랑). 음성 없음(자막 중심 — 무음 재생 대비). 효과음: 새 STEP 차임·장면 넘김 작은 소리, 장면 사이 0.4 s 교차 페이드(11-09). 읽는 대본 = `대본.md`.
보안: 화면의 QR·토큰 주소는 모두 **로컬 시연 서버(127.0.0.1)의 시험 토큰**만 — 실제 Vercel 토큰·QR 은 영상에 넣지 않음. Revit 화면은 guide_shots(QR 가림) — 24–27 은 87차 캡처(11-09 반영).

## 투영 장면(5·6·8) 동작
1. Revit 화면 위에 [서버 연동] QR 창(실캡처 12, QR 부분은 시연 QR 로 덮음)이 뜸.
2. QR 카드가 창에서 떨어져 왼쪽(화면 폭 22 %)으로 이동·확대, 아래에 "휴대폰 카메라로 찍기".
3. QR 네 모서리에서 점선 4개가 오른쪽으로 뻗고, 점선 직사각형이 펼쳐지며(0.6 s) 그 안에 휴대폰 틀 + 실제 화면 녹화가 나타남.
4. 휴대폰 녹화 위에 탭 파문 + 짧은 설명표(어느 칸에 무엇을 넣는지).
5. 저장 순간 휴대폰 → 서버 아이콘으로 점선 위 점이 흐름 → 서버 화면(타임라인 웹)으로 전환.
