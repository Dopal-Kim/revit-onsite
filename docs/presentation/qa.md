## 추가로 나올 수 있는 질문
- **최상층은 왜 3개층 규칙을 통과하나?** — 3개층 존치는 위층 타설 하중을 나누려는 것이다. 지붕 슬래브 위에는 타설이 없다는 팀 해석이다 [가정]. 강도(공시체) 기준은 그대로 요구한다(S7). (outline §5, scenario_validation S7)
- **"검측요청 전에 공시체 기록 없음" 경고는 뭔가?** (시연 중) — [승인 기록] 시각이 실제 시계(발표 날)라 데모 날짜 12-31 보다 앞서서 생긴다. 실제 현장에서는 요청 제출이 공시체 시험 뒤라 이 경고가 안 뜬다. 순서가 바뀌면 이렇게 드러난다. (outline §3-0 ③)
- **9F 층 표지가 '해체 금지'인데 9F-B1 은 요청 가능 아닌가?** (시연 중) — 한 층에 존치 구역(A2·B2)이 하나라도 있으면 층 상태 줄은 '동바리 해체 금지'다. 구역 줄에서 9F-B1 은 따로 보인다. (HANDOFF 0-0 18:55 층 표지)
